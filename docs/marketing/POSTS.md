# Kit de posts e textos de divulgação — Papelzinho

Responsável: Marketing · revisão: Designer · versão 18/11/2026.
Nada aqui é publicado: o Rodrigo publica, e apenas após a aprovação do PO e a liberação de segurança. Endereço oficial: https://papelzinho.app.

## 1. Regras que valem para todas as peças

- Tom: caloroso, simples e direto. Trata a pessoa por "você". Uma ideia por frase. Palavras do dia a dia (a pessoa pode ter 70 anos).
- Sem gíria que envelhece: nada de "galera", "bora", "top". Emoji só 🎁 no WhatsApp; ⚠ e ✓ só como ícone junto com texto.
- Termos fixos: amigo secreto · grupo · convite · organizador · participante · sorteio · lista de desejos · link pessoal · link de organizador. Nunca "token", "admin", "lista de presentes".
- Não prometer recursos ainda não entregues: a lista de desejos só chega com a LST-04; o sorteio com a SRT-03.
- Não compartilhar o link de organizador nem o link pessoal nos grupos. Só o convite vai para o grupo.
- Datas no formato `24/12/2026`; dinheiro `R$ 50,00`.

## 3. Texto de divulgação para grupos (WhatsApp)

Cópia pronta para o organizador colar no grupo da família, dos amigos ou da equipe:

```
Oi, pessoal! Criei um amigo secreto no Papelzinho: *NOME DO GRUPO* 🎁

Troca de presentes: DATA (ex.: 24/12/2026)
Valor máximo do presente: VALOR (ex.: R$ 50,00)
LOCAL (opcional: ex.: Casa da Vó Maria)

Entre pelo convite, só com o seu nome. Sem cadastro e sem senha:
LINK DO CONVITE (https://papelzinho.app/g/...)

Guarde seu link pessoal depois de entrar. É por ele que você vê quem tirou no sorteio. Não compartilhe o link de organizador — ele é só seu.
```

Como usar: substitua `NOME DO GRUPO`, `DATA`, `VALOR`, `LOCAL` e `LINK DO CONVITE`. A linha de Local some quando não houver local.

## 4. Mini-kit do teste real (REL-01)

Para o Rodrigo compartilhar com os 2 grupos reais (família e amigos) no teste de 26 a 28/11. Nada é publicado além desses grupos.

**Convite ao teste**
```
Oi! Vamos testar o Papelzinho, o app de amigo secreto que estou ajudando a lançar.

Criei um grupo para a nossa troca: NOME DO GRUPO
Data da troca: DATA
Valor máximo: VALOR

Entre pelo convite com o seu nome (sem cadastro e sem senha):
LINK DO CONVITE

Me conte o que achou: foi fácil criar? A entrada foi rápida? Ficou alguma dúvida?
🎁
```

**Guia rápido para o organizador (teste real)**
1. Acesse https://papelzinho.app e crie o grupo (nome, valor máximo, data da troca).
2. Copie o link do convite e envie apenas ele para o grupo do WhatsApp.
3. Não compartilhe o link de organizador.
4. Quando todas as pessoas entrarem (mínimo 3), confira no painel do organizador se o sorteio já está disponível e, se estiver, faça o sorteio.
5. Se o sorteio foi feito, cada pessoa abre o próprio resultado pelo link pessoal.

**O que observar e registrar (feedback para o time)**
- Foi fácil criar o grupo em menos de 2 minutos?
- Cada pessoa entrou em menos de 30 segundos pelo convite?
- Algum link quebrou ou deu erro?
- Se o sorteio estiver disponível: o sorteio e a revelação funcionaram?
- Alguma frase ou tela ficou confusa?

O Rodrigo encaminha as respostas para o 00 Orquestrador, que registra os bugs S1/S2 para correção antes do lançamento de 28/11.
